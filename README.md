# Expense Tracker

A simple menu-driven Expense Tracker application built using Python.

## Features

* Add new expenses
* Store date, category, amount, and optional note
* Save expenses in a CSV file
* View all recorded expenses
* Calculate total amount spent
* Display category-wise spending summary
* Handle invalid input using exception handling

## Technologies Used

* Python
* CSV
* File Handling
* Functions
* Exception Handling



## CSV Data

The application stores expense records in a CSV file with the following information:

```text
Date, Category, Amount, Note
```

Example:

```text
12-08-2026,Food,250,Lunch
12-08-2026,Travel,100,Bus
```
